# Manejo de archivos en Python

Ejercicio introductorio para leer archivos de texto codificados en UTF-8 y
escribir su contenido en la salida estándar.

## Ejercicio

- `read_file.py`: define `read_file(filename="")`, que lee el archivo usando
  `with` y muestra su contenido sin modificarlo.

## Requisitos

- Python 3.8.
- Sin módulos importados.
- Los scripts comienzan con `#!/usr/bin/env python3` y siguen PEP 8.
