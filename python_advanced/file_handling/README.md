# Manejo de archivos en Python

Ejercicios introductorios para leer y escribir archivos de texto codificados
en UTF-8.

## Ejercicio

- `read_file.py`: define `read_file(filename="")`, que lee el archivo usando
  `with` y muestra su contenido sin modificarlo.
- `write_file.py`: define `write_file(filename="", text="")`, que escribe el
  texto en el archivo usando `with` y devuelve el número de caracteres escritos.

## Requisitos

- Python 3.8.
- Sin módulos importados.
- Los scripts comienzan con `#!/usr/bin/env python3` y siguen PEP 8.
